# QuranKareem — النسخة الموحّدة

دمج مشروعَي **QuranKareem V2** و**تلاوة** في مشروع واحد، مبني حول **ثلاثة أبواب** من الواجهة الرئيسية.

## الأبواب الثلاثة

| الباب | الصفحة | المزايا |
|-------|--------|---------|
| **القراءة** | `#pg-read` | المصحف كاملاً (١١٤ سورة) بخط عثماني • الترجمة (إنجليزي/فرنسي/إسباني) • **التفسير الميسّر** لكل آية • **تلوين التجويد مفعّل افتراضياً** (نظام تنزيل + مفتاح ألوان، والزر يُطفئه ويحفظ الاختيار) • البحث في السور • تكبير/تصغير الخط • **علامة آخر قراءة** واستئنافها • أدوات لكل آية: استماع، تأمّل، سؤال المساعد، حفظ الموضع، إرسالها إلى حلقة التحفيظ |
| **الاستماع** | `#pg-listen` | **١٣ قارئاً** بهوية جغرافية • وضعان: **آية آية** أو **السورة كاملة** • موجة صوتية • تكرار • تحكم بالصوت • تنقّل بين الآيات • **مؤقّت نوم** (١٠/٢٠/٣٠/٦٠ د) |
| **الأطفال** | `#pg-kids` | **٥ مستويات · ٥٨ سورة** = جزء عمّ (٣٠) في ثلاث درجات (١١ · ١٢ · ١٥) ثم **جزء تبارك (٢٩)** ١١ سورة ثم **جزء قد سمع (٢٨)** ٩ سور — كلٌّ مرتّب من الأقصر إلى الأطول لا بالترتيب المصحفي • بطاقات ملوّنة كبيرة • **زر تشغيل واحد** بلا إعدادات • **تكرار تلقائي** ١/٣/٥/٧ لكل آية • **«ردّد بعدي»**: سكتة بطول الآية ليردّد الطفل خلف القارئ • **نقاط الآيات قابلة للضغط** للقفز مباشرةً (لازمة في سور تبلغ ٥٦ آية) • **نجوم تحفيزية** تُحفظ في الجهاز • احتفال عند إتمام سورة أو مستوى • صفر ترجمة/تفسير/تجويد |
| **التعليم** | `#pg-teach` | **🎙️ وضع التسميع الصوتي** (اقرأ بصوتك فيتتبّعك ويظلّل ويكشف موضع التوقف — Web Speech API أصلي) • نطاق آيات (من/إلى) • **تكرار الآية** و**تكرار الدورة** (حتى ٢٠) • **سكت بين الآيات** (٠–٨ ث) أو **سكت تلقائي حسب طول الآية** • **سرعة التلاوة** (٠٫٥–١٫٥×) • **تظليل كلمة بكلمة** (توقيتات دقيقة من Quran.com مع العفاسي، وتقدير خطّي للبقية) • **إبقاء الشاشة مضاءة** أثناء الحفظ • شريط تقدّم وتنقّل |

صفحات مساندة محفوظة من V2: الصلاة والقبلة، الحلقات، المساعد الذكي، وضع التأمل، المفضلة، ٦ لغات.

## الملفات

```
index.html      ← الهيكل + CSS كامل
app.js          ← كل JavaScript (i18n، القراءة، الاستماع، التعليم، الصلاة، المساعد)
sw.js           ← Service Worker (Network-First لملفات الموقع)
_redirects      ← توجيه الروابط النظيفة على Cloudflare
guardian.js     ← طبقة النسبة (ALTAYEB GUARDIAN)
icon-192/512.png← أيقونات PWA وشاشة القفل
manifest.json   ← PWA + اختصارات للأبواب الثلاثة
```

## مصادر البيانات (بلا backend)

| الاستخدام | المصدر |
|-----------|--------|
| نص القرآن | `api.alquran.cloud/v1/surah/{n}/ar.uthmani` |
| التفسير | `api.alquran.cloud/v1/surah/{n}/ar.muyassar` |
| الترجمة | `en.sahih` / `fr.hamidullah` / `es.asad` |
| صوت الآية | `cdn.islamic.network/quran/audio/{br}/{id}/{globalAyah}.mp3` — البت `{br}` يختلف بين القرّاء (64/128/192) |
| صوت السورة | `mp3quran.net` (٣ خانات) — القرّاء الذين لهم `surahBase` فقط |
| الصلاة والقبلة | `api.aladhan.com` |

### القرّاء (١٣ — بهوية جغرافية)
مصر: الحصري، المنشاوي، عبدالباسط، البنّا · الشام: **أيمن سويد** (آية-آية فقط) · الحجاز: ماهر المعيقلي، عبدالله بصفر، أبوبكر الشاطري، هاني الرفاعي، الحذيفي · نجد: السديس، سعود الشريم · الخليج: العفاسي.

> كل رابط ومعدّل بت مُتحقَّق منه فعلياً. المفتاح: `cdn.islamic.network` يستخدم **الرقم العالمي للآية** (1..6236) لا `سورة+آية`، وكل قارئ على معدّل بت مختلف — بناؤه بـ128 ثابتاً يُنتج 403 (كان سبب اختفاء القرّاء الجدد). روابط السور الكاملة في V2 (`audio-surah/...`) لا تعمل، واستُبدلت بخوادم mp3quran.

## الخطوط والترجمات (جديد)

**خط المصحف قابل للتبديل** (يُحفظ في `qk_font`): عثماني حفص معتمد · نسخ أميري · Scheherazade New · Noto Naskh · **نستعليق (Noto Nastaliq Urdu)** · ثلث/رقعة (Aref Ruqaa) — كلها OFL من Google Fonts، عدا العثماني من quran.foundation.

**ترجمات التفسير**: إنجليزي/فرنسي/إسباني + **أردو (جوناگڑھی/جالندھری) بخط النستعليق** + **فارسي (مکارم)** + تركي — الأردية والفارسية تُعرض بالنستعليق من اليمين تلقائياً.

> خط الثلث الكامل للمصحف غير متوفر كخط ويب موثوق (الثلث خط زخرفي)؛ أُتيح Aref Ruqaa كأقرب بديل للعرض.

## صفحات المشروع (جديد)

- **تواصل معنا** (`/contact`): نموذج يفتح بريد المستخدم (mailto) — بلا backend.
- **حقوق المشروع** (`/license`): رخصة صدقة جارية — يُسمح بالنسخ بنيّة الخير بشرط إعادة النشر مجّاناً دون مقابل، ويُمنع البيع.

**المصمم وصاحب فكرة المشروع: الفنان الطيب عامر** — مذكور في الفوتر وصفحة الحقوق.

## النطاق والنشر

**النطاق الرسمي:** `qurankarem.org` — مُشترى من **Cloudflare**. النشر على **Cloudflare Pages**: اربط المستودع، Build فارغ، Output `/`، ثم اربط النطاق من لوحة Cloudflare (Custom domain). بريد التواصل الرسمي: `info@qurankarem.org` (يُفعّل من Email Routing في Cloudflare).

الوسوم الجاهزة: `canonical` + Open Graph + Twitter Card + `manifest.id` كلها تشير إلى `https://qurankarem.org/`.

## النشر (Cloudflare Pages)

ارفع كل الملفات كما هي. Build command فارغ، Output directory `/`.

**`_redirects` ضروري** (مرفق): يحوي `/*    /index.html    200` لتعمل الروابط النظيفة (`/learn` …). لا تضف `_headers`.

### الروابط المباشرة
`/read` · `/listen` · `/learn` · `/kids` · `/prayer` · `/supporters` · `/advertise` · `/contact` · `/license` — وكذلك `/read/2/255` لفتح آية بعينها مباشرةً.

**عند تعديل `app.js` غيّر رقم النسخة** في `index.html` (`app.js?v=N`) وفي `sw.js` معاً، وإلا بقي الملف القديم في الكاش.

## إصلاح مهم (v48)

`stripBsm` كان يفشل في فصل البسملة عن أول آية كلما أرجع الـ API **الياء الفارسية U+06CC**
في «الرحيم» — لأن `normQuran` كان يُطبَّق **بعد** `stripBsm` لا قبله، فتفشل المطابقة وتبقى
البسملة مكرّرة. أصاب ذلك **٦ مواضع**: القراءة، التجويد، الاستماع، التعليم، ووضع الأطفال.
الإصلاح سطر واحد داخل `bareAr` (تطبيع قبل التجريد)، ومُتحقَّق منه على **٣٨ سورة**: صفر تكرار.

## التنقّل

الأبواب الأربعة في كل الصفحات: شريط سطح المكتب · التنقّل السريع للجوال · قائمة الموبايل · الفوتر.
**المساعد الذكي مُزال من التنقّل** حتى تفعيله — يبقى في بطاقة الرئيسية وعلى `/assistant`.
زر «الرئيسية» أُزيل من التنقّل السريع (الشعار يؤدّيها) لتفادي فيض الترويسة.

## الداعمون والإعلانات

- **`/supporters`** — أربع درجات (راعٍ رئيسي · داعم · مساهم · دعم عيني)، وشريط هادئ أعلى الفوتر
  يختفي تلقائياً إن لم يوجد داعم. الشعارات رمادية وتتلوّن عند المرور.
- **`/advertise`** — سياسة قبول ورفض صريحة، وأماكن الظهور وأماكن المنع، بلا جدول أسعار.
- **البيانات في `supporters.json` وحده** والشعارات في `/sponsors/` — تُحدَّث دون لمس الكود.
- **لا شبكة إعلانات ولا تتبّع.** شعارات ثابتة بمراجعة يدوية فقط.

## نقطة مفتوحة

المساعد الذكي ما زال يستدعي `api.anthropic.com` مباشرة من المتصفح بلا مفتاح — يحتاج وسيطاً (Cloudflare Worker) قبل أن يعمل فعلياً.
